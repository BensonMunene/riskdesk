Examples
# session auth in the browser, or HTTP Basic from scripts
curl -u cio:riskdesk http://localhost:8000/api/portfolios/1/risk/

# pre-trade check from Python
import requests
r = requests.post("http://localhost:8000/api/portfolios/1/whatif/",
                  auth=("cio", "riskdesk"),
                  json={"trades": {"NVDA": -5000, "AMD": 8000}})
print(r.json()["comparison"]["verdict"])

# optimiser
requests.post(".../api/portfolios/2/optimize/", auth=("cio","riskdesk"),
              json={"method": "risk_parity", "w_max": 0.3}).json()["weights"]
Responses are plain JSON; the browsable API renders them in the browser. All amounts are fractions of NAV unless the key ends in _dollar.
